# Retrieval-Augmented Generation (RAG)

RAG systems combine retrieval and generation capabilities to enhance AI responses with external knowledge.

## Components

- **Retriever**: Finds relevant documents
- **Generator**: Creates responses using retrieved context
- **Knowledge Base**: Stores embedded information
